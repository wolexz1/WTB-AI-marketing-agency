# Awesome DESIGN.md

Project-local helper skill inspired by:
https://github.com/voltagent/awesome-design-md

## What This Adds

Awesome DESIGN.md is a curated collection of markdown design-system files. Each `DESIGN.md` describes how a brand/site should look and feel so AI coding agents can generate more consistent UI.

Use this skill to:

- Pick a design inspiration direction.
- Translate inspiration into WTB's own brand language.
- Create or update a WTB-specific `DESIGN.md`.
- Keep future pages visually consistent.
- Avoid repeating generic agency/AI website patterns.

## Important Rule

Do not copy another brand's design identity directly. Use references for structure, atmosphere, hierarchy, and interaction patterns only. WTB must remain its own brand.

## Good Reference Directions For WTB

WTB should borrow principles from:

- Premium editorial marketing sites: confident type, strong photography, clear sections.
- AI/product sites: precise systems, dashboards, speed, intelligence.
- Creative agency sites: art direction, human work, culture, proof.
- Conversion landing pages: clear offer, trust, CTA rhythm, low friction.

Avoid:

- Overused purple AI gradients.
- Generic SaaS hero sections.
- Copying logos, proprietary color systems, or exact layouts.
- Too much developer-tool styling for a marketing agency audience.

## WTB DESIGN.md Workflow

When using this skill:

1. Define the page goal.
2. Choose a reference mood, not a brand clone.
3. Translate that mood into WTB's palette, type scale, imagery, spacing, and CTA rules.
4. Update or create `DESIGN.md` when the design direction becomes stable.
5. Apply the design to HTML/CSS/JS only unless the user asks for a framework.
6. Check mobile layout, image weight, CTA clarity, and SEO metadata before finishing.

## WTB Design Tokens To Preserve

- Brand name: WTB / Wolexzthebrand AI Marketing Agency.
- Voice: confident, practical, business-focused.
- Primary actions: Send us a brief, Book a call, Chat with us, Website Brief.
- Visual tone: premium Nigerian AI-powered marketing agency.
- AI role: execution advantage, not the only service.
- Avoid writing from "I"; use "we."

## When To Create A Root DESIGN.md

Create or update `DESIGN.md` when:

- The user asks for a new design direction.
- We add multiple new pages.
- We change the visual system.
- We need future agents to understand WTB's design rules quickly.

The root `DESIGN.md` should include:

- Visual theme and atmosphere
- Color palette and roles
- Typography rules
- Component styling
- Layout principles
- Motion rules
- Image/art direction
- Responsive behavior
- Do's and don'ts
- Page examples and CTA logic

## Quick Prompt Pattern

When adapting a design reference, use:

> Use the structure and polish of [reference direction], but translate it into WTB's own AI marketing agency identity. Keep WTB's blue/gold/black premium direction, Nigerian market context, fast marketing execution positioning, and conversion-focused CTA flow. Do not copy the source brand.
