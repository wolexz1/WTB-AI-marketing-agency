# Impeccable

Project-local copy of the Impeccable frontend design skill from:
https://github.com/pbakaus/impeccable

Use this skill when improving WTB website design quality, UX, motion, polish, accessibility, visual hierarchy, copy clarity, responsive behavior, and frontend performance.

## What It Does

Impeccable is a frontend design skill for making interfaces feel more intentional and less generic. It helps with:

- UX review and critique
- Visual hierarchy
- Typography and spacing
- Color strategy
- Responsive design
- Motion and micro-interactions
- Accessibility
- UI performance
- Landing pages and marketing pages
- Forms, buttons, empty states, and interaction details
- Reducing common AI-generated design patterns

## How To Use It In This Project

Before design work:

1. Look for product and design context in the project.
2. Treat WTB as a brand/marketing website, not a SaaS dashboard.
3. Make design choices that improve conversion, trust, speed, and clarity.
4. Avoid generic AI-looking design patterns.
5. Test mobile and desktop layout after edits.

## Useful Impeccable Commands

- `audit`: review a page for UX, accessibility, responsiveness, and performance.
- `polish`: final design quality pass before publishing.
- `optimize`: improve frontend performance and loading behavior.
- `adapt`: improve mobile/tablet/desktop behavior.
- `clarify`: improve UX copy, labels, and form text.
- `animate`: add purposeful motion without slowing the page.
- `typeset`: improve type hierarchy and readability.
- `layout`: fix spacing, rhythm, alignment, and visual balance.
- `bolder`: make a bland section more memorable.
- `quieter`: calm down a section that feels too loud.

## Design Rules To Keep In Mind

- Every section must have a clear job.
- Avoid repeating the same image style on every page.
- Do not use nested cards.
- Avoid generic gradient text and overused AI/SaaS visuals.
- Keep body text readable and line lengths comfortable.
- Use motion only when it helps attention, orientation, or delight.
- Optimize image weight before publishing.
- Make mobile layout feel designed, not squeezed.
- Keep the WTB voice confident, practical, and conversion-focused.
