# Distribb Hub Setup for WTB

Date: June 13, 2026
Repo referenced: https://github.com/Bomx/distribb-skill

## What Distribb is

Distribb is not a website plugin.

It is an SEO operations hub for AI agents.

You still use your own AI for:

- writing
- planning
- strategy
- editing

Distribb handles the SEO infrastructure around that work:

- keyword research
- internal link suggestions
- backlink exchange targets
- article calendar
- CMS publishing
- Google Search Console pull-through
- social media repurposing
- Microworkers campaign management

Primary references:

- `https://raw.githubusercontent.com/Bomx/distribb-skill/main/README.md`
- `https://raw.githubusercontent.com/Bomx/distribb-skill/main/SKILL.md`

## What it can do for the WTB website

For this website, Distribb can help in five serious ways:

### 1. Better keyword research for blog and service pages

Instead of guessing what to write next, Distribb can return:

- keyword ideas
- search volume
- keyword difficulty
- related keyword angles

That helps WTB decide:

- what Nigeria pages to build next
- what Lagos and Abuja pages deserve priority
- what blog topics have stronger buyer intent

### 2. Internal linking support

Distribb can suggest which published pages should be internally linked from a new article.

That matters for WTB because your site is now building clusters around:

- digital marketing agency pages
- AI marketing agency pages
- pricing pages
- buyer guides
- international-entry pages

Internal linking is one of the easiest ways to help Google understand which pages matter most.

### 3. Backlink exchange opportunities

This is one of its biggest promises.

Distribb says it can provide backlink targets from real businesses in its network.
When your article includes relevant approved target links, your project earns credits and can receive backlinks in return.

For WTB, this could help with:

- building domain trust
- supporting new money pages
- helping blog clusters get authority faster
- giving newer Nigeria pages a better chance to index and rank

Important caution:

Backlinks only help if:

- the linking sites are actually decent
- the links are topically relevant
- the article itself is useful

So Distribb can help, but it should not replace judgment.

### 4. Publish workflow and content calendar

Distribb can store articles, track statuses, and publish to connected CMS platforms.

That would help WTB if you want a cleaner workflow for:

- planned topics
- drafted pages
- scheduled publishing
- batch content operations

### 5. Search Console and performance visibility

Distribb can pull Search Console performance if connected.

That would help WTB see:

- top queries
- top pages
- clicks
- impressions
- CTR
- average position

That is useful for deciding:

- which pages to refresh
- which keywords are close to page 1
- which blogs deserve backlinks
- which service pages need stronger support

## What WTB needs before this is usable

Distribb requires:

### Required

- a Distribb account
- a `DISTRIBB_API_KEY`

### Important detail

On the `Free Agentic` plan, keyword research can return `HTTP 402` until the user adds:

- `DataForSEO` keys, or
- `Ahrefs` API key

Setup pages mentioned by the skill:

- sign-up: `https://distribb.io/agentic`
- API key: `https://distribb.io/settings`
- SEO keys: `https://distribb.io/settings#seo-keys`

## How to install it outside this sandbox

The repo says the install command is:

```bash
npx skills add Bomx/distribb-skill
```

Then set the key:

```bash
export DISTRIBB_API_KEY=your_api_key_here
```

After installation, Codex should be restarted so the new skill is picked up.

## Why I did not fully install it from here

This environment does not let me complete the full external install flow safely because:

- it requires network install
- it requires your real API key
- the skill is meant to live in your Codex skills environment, not just inside the website folder

So the correct next step is for you to install it in your actual Codex environment once you are ready to use your Distribb account.
